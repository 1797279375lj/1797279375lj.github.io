# 陆骏的个人工作台 | JUN'S DIGITAL WORKSPACE

陆骏 Philip 的个人网站：个人品牌展示、工业品 B2B 大客户销售经验、AI 工具与自动化项目、学习与成长记录。

纯静态网站，无框架、无构建步骤、无外部依赖，打开 `index.html` 即可浏览。

## 目录结构

```
juns-digital-workspace/
├── index.html          # 页面（单页：首页/关于我/AI工具箱/项目作品/学习笔记/最新动态/联系）
├── assets/
│   ├── styles.css      # 全部样式（深蓝/黑白/灰配色，响应式适配手机/平板/电脑）
│   └── script.js       # 移动端导航、滚动淡入动画、留言表单演示逻辑
├── crm/
│   ├── index.html      # 客户管理 CRM 页面
│   ├── crm.css         # CRM 样式
│   └── crm.js          # CRM 逻辑（数据层 + 界面层，数据存浏览器 localStorage）
└── README.md           # 本说明
```

## CRM 系统说明

- 入口：网站导航「CRM 系统」，或直接访问 `/crm/`。
- 功能：客户档案（公司/联系人/电话/微信/行业/地区/来源/等级/预计金额）、销售漏斗 7 阶段（线索→已联系→需求确认→报价中→谈判中→已成交/已流失）、跟进记录时间线、下次跟进到期/逾期提醒、搜索与阶段筛选、导出 CSV、导出/导入 JSON 备份。
- 数据存储：只存在访问者本机浏览器的 localStorage，不上传服务器。换设备或清浏览器数据会丢失，重要数据请定期导出备份。
- 参考：GitHub 上同类轻量 CRM 的通行做法（原生 JS + localStorage + CSV 导出），按本人销售流程定制实现，未直接套用第三方代码。

## 内容真实性说明

- 经历、数据（近 100 个新客户、30+ 成交单、参与合同额 2700 万+）均来自本人真实简历与工作记录。
- 「AI 工具箱」的工具均如实标注状态（开发中 / 规划中），未上线的功能不做虚假演示。
- 留言表单目前是前端演示，不会发送数据；后续接入表单服务（如 Formspree 免费版）后替换 `assets/script.js` 中表单处理逻辑即可。
- 默认未公开私人邮箱与电话，避免垃圾信息；如需公开，在 `index.html` 联系区有注释位置可填入公开联系邮箱。

## 如何更新内容

1. 改文字：直接编辑 `index.html` 对应区块（每个区块有中文注释，如 `<!-- 项目作品 -->`）。
2. 加一个新项目：在「项目作品」区复制一个 `<article class="card project reveal">…</article>`，改标题、介绍和状态标签（已上线 `badge-live` / 进行中 `badge-dev` / 规划中 `badge-plan`）。
3. 加一条动态：在「最新动态」区复制一个 `<article class="update-item reveal">…</article>`，改日期和内容，新的放最上面。
4. 改样式：颜色集中在 `assets/styles.css` 开头的 `:root` 变量里，改 `--navy` / `--accent` 即可整体换色。
5. 改完把整个文件夹重新上传/推送到部署平台即可生效。

## 维护说明

- 日常维护只有两件事：更新 `index.html` 的文字内容、定期检查外部链接是否有效。
- 网站无数据库、无后端、无付费 API，不产生运行费用。
- 每次大改前先把旧版文件夹复制一份备份，出问题可直接回滚。
- 后续增加 AI 工具时，建议每个工具单独建一个子目录（如 `tools/model-compare/`），与主页解耦，互不影响。
